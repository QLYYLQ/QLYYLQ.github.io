数据边界

D1/D2 的 32k 列来自同一批完整生成的前 32,768 个原始生成 token 重新解码 判分。样本全文、prompt token ID 与生成 token ID 只保留在集群 raw/，没有 进入本 zip。tp2_allwrong_tails.jsonl 是用户明确要求的 1,500 字符尾部导出， 不是完整生成文本。

本包包含 compact 表格、代码、来源、报告和验证证据。MANIFEST.tsv 与 SHA256SUMS 覆盖包内交付文件；外部 .validation.json 记录 ZIP CRC 和逐文件 复核。当前环境没有已配置的 Mac 写入连接，因此提供本机与共享文件路径供下载， 不声称已经直接写入 Mac 文件系统。
