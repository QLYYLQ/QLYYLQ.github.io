KiCad 10 不开图形界面能做什么：五样辅助工具里两样做不了

PCB工具链工具核实本机实测 + 出处1 样可行2 样部分可行2 样做不了

背景：不用 CUA 的试做环境只给模型 kicad-cli、KiCad 自带 Python（pcbnew）和 Freerouting。两道难题的探针显示，模型在 pcbnew 的接口细节、看不见板子、没有“从原理图更新 PCB”上各花了几十步，所以计划做五个辅助工具补能力。做之前要先确认这些能力在无界面路径里到底存不存在。

结论一句话：KiCad 10 的“设计修改”类操作在无界面路径里基本不存在。能自动化的是检查、导出、文件级改写和批量布线往返：DRC/ERC、Gerber/钻孔/STEP/PDF/SVG/3D PNG、网表/BOM、铺铜重填、用 pcbnew 直接读写板子，以及 DSN→Freerouting→SES 的整板布线。不能自动化的是设计推进：从原理图更新 PCB（F8）、交互式推挤/差分对/等长调谐、原理图编辑。

落到五个辅助工具：drc_diff 可行；board_view 部分可行——3D PNG 能直接出，2D 版图位图没有子命令，只能先出 SVG/PDF 再栅格化；pcbnew 安全封装部分可行——只能包文件级编辑，DRC 必须转 kicad-cli；sync_from_schematic 和交互式布线两样不可行，只能自己写或留给 CUA 榜。

IPC API 不是替代品：KiCad 10 的 IPC 必须有一个正在运行的 GUI，只覆盖 PCB 编辑器，不能导出，没有原理图 API。它能做的是在开着的 KiCad 里增删改封装/走线/过孔、重填铺铜、保存文档，换不到 F8 和推挤布线。官方文档写的是 headless 支持要到 11。

这一页只记核实结论，不改任何题包。两样做不了的，出路只有两条：自己实现（网表对比 + 按网表补封装；Freerouting 批量布线 + 单网络布线函数），或者留给 CUA 榜。

1/5可行：drc_diff
2/5部分可行：board_view（3D 可出、2D 要转）、pcbnew 封装
2不可行：sync_from_schematic、交互式布线

过程一步一步

  1. 01
    方法

    三条路径逐项对照，能做/不能做都给出处

    三条无界面路径：kicad-cli（10.0.7，本机实测）、IPC API（KICAD_IPC_API=ON 的 10.0.7，需要 GUI）、pcbnew 脚本（KiCad 自带 Python 3.9.13 里的 10.0.7 绑定）。

    每一项操作分四档记：有（官方接口直接支持）、部分（只在某些子命令/条件下支持）、无（没有该接口）、名义有/实测坏（API 存在但本机或已知 issue 里不可用）。本机跑过的写“本机实测”，联网结论给 URL 和抓到的原文，查不到的写“没查到”。

  2. 02
    能做

    DRC/ERC、导出、铺铜重填、文件级读写

    • DRC / ERC：kicad-cli pcb drc、sch erc 都有；pcb drc 还带 --schematic-parity（原理图与 PCB 一致性）和 --refill-zones，配 --save-board 才把重填结果落盘。
    • 导出：pcb export 出 Gerber/钻孔/STEP/PDF/SVG 等；pcb render 出 3D PNG（本机实测生成成功）。pcbnew 的 PLOT_CONTROLLER 能出 SVG/PDF/Gerber/DXF 和 VRML，没有 STEP。
    • 铺铜与器件：pcbnew 有 ZONE_FILLER、可以增删改封装/走线/过孔；IPC 也有 CreateItems/UpdateItems/DeleteItems 和 RefillZones。
    • 网表与接口文件：sch export netlist 生成网表；pcbnew 有 ExportSpecctraDSN/ImportSpecctraSES，这是接 Freerouting 的路子。
  3. 03
    做不到

    F8、推挤布线、差分对、等长：三路都没有

    从原理图更新 PCB（F8）：kicad-cli 没有 netlist 更新命令；IPC 10 没有原理图 API；pcbnew 没有 netlist updater 绑定。三路都没有。这解释了 cynthion 探针里模型为什么手搬封装，最后 32 个封装库 ID 和原理图对不上、还漏放 4 颗电阻。

    交互式推挤布线（shove/walkaround）：只有 GUI 有。kicad-cli 无、IPC 无、pcbnew 无。这一条最要紧：Glasgow 探针里模型自己写布线器，72 步没收敛，就是因为没有这个能力，而 Freerouting 只能整板或指定网络批量布，不能当交互式布线用。

    差分对布线与等长/时域调谐：同样只有 GUI 有，三路都没接口。

    另外两处：IPC 的 InjectDrcError 只是注入标记，不是跑 DRC；pcbnew 的 WriteDRCReport 在 10.0 standalone 实测段错误，所以判分器一律走 kicad-cli pcb drc，不要用 pcbnew 跑 DRC。

    检查查什么结果说明
    F8 更新从原理图更新 PCB不过kicad-cli / IPC / pcbnew 都没有
    推挤布线shove / walkaround不过仅 GUI
    差分对/等长diff pair / length tuning不过仅 GUI
    DRCkicad-cli pcb drc通过含 parity 与 refill-zones
    3D PNGkicad-cli pcb render通过本机实测
    pcbnew DRCWriteDRCReport不过10.0 standalone 段错误，改用 kicad-cli
  4. 04
    影响

    五个辅助工具：一个可行、两个部分可行、两个做不了

    drc_diff：可行。kicad-cli pcb drc 本机实测正常，5 条故意违规全部报出；--format json、severity、--exit-code-violations、--refill-zones、--save-board 都在 help 里。落地时按“规则类型 + 严重级别 + 位置/对象”归并后 diff，不要按条数比——项目侧实测同一文件 DRC 计数会漂（短路 2–7 条、总数 141 不变）。

    board_view：部分可行。kicad-cli pcb render 无 GUI 实测生成 PNG（8907 字节），但它是 3D 光照渲染，不是 2D 版图截图；看层、走线、丝印细节仍要 2D 的 SVG/PDF，而 2D 位图没有子命令，只能 pcb export svg 或 pcbnew 的 PLOT_CONTROLLER 出矢量，再外部栅格化成 PNG——这条转换链报告没测。

    pcbnew 安全封装：部分可行。可包 LoadBoard/SaveBoard、增删改封装/走线/过孔、ZONE_FILLER、PLOT_CONTROLLER、ExportSpecctraDSN/ImportSpecctraSES；接口层要直接拒绝 F8、DRC、布线三类调用，DRC 转 kicad-cli。另有一个时间账：SWIG 绑定自 9.0 弃用、计划 11.0 移除，封装层要能整体换实现——但 IPC 在 10 需要 GUI，当不了无头替代，到 11 才可能。

    sync_from_schematic：不可行。要补只能自己写：sch export netlist --format kicadxml 拿网表，再用 pcbnew 读焊盘和网络做对比合并，然后列出差异。它不能等价于 F8（F8 还处理位号、封装库选择、网络类），只能覆盖“补齐缺件、更新连接”；pcb drc --schematic-parity 只报差异、不更新，而且要完整工程和已标注的原理图。

    交互式布线：不可行，Freerouting 也顶不上。它只能整板或按 netclass 批量布，报告没查到“只布某个 net”的选项（--debug.filter_by_net 只限制调试动作）；没有“保留已有走线”的开关（ripup_allowed 默认 true），要保留只能先在 KiCad 里锁定；SES 导回会删掉所有未锁定走线。所以替代方案只能是“整板/按类批量 + 锁定保护”，推挤、差分对、等长仍只能 CUA。

  5. 05
    边界

    核实的边界

    • 本机实测是 macOS 上的 KiCad 10.0.7 release build；Linux 版的行为没有实测，只核对了文档和 issue。评测环境如果换到 Linux，pcb render 要现在目标机冒烟。
    • IPC API 的结论基于 10.0 的文档与绑定：必须有运行中的 GUI，且只覆盖 PCB 编辑器，不支持 plotting/export；11 会不会加 headless 和原理图支持，报告没查。
    • 报告里几处“查不到”的项保留原样，没有补推断：例如官方 CLI/Python 的 netlist 更新方案、IPC 10.0 的专用 DRC 命令。
    • 这条核实只回答“接口有没有”，不回答“写出来好不好用”；辅助工具的实际收益要等实现之后用同一批探针复测。
看点

先核实再实现：五个辅助工具里两个根本没有底层接口，如果直接开工，会做到一半才发现要自己重写 KiCad 的 netlist updater。

IPC 不是万灵药：它只是在开着的 GUI 上开一个口子，能做的事和 pcbnew 高度重叠，换不到 F8 和推挤布线；官方说 headless 要到 11。

3D 渲染不等于 2D 版图：pcb render 出的是光照图，看层和丝印还得 SVG/PDF，board_view 要做两件事。

判分器和辅助工具都要避开 pcbnew 跑 DRC：10.0 standalone 的 WriteDRCReport 会段错误，统一走 kicad-cli。

工具能力要写进题面和榜单：给了 Freerouting 就要说明它不能按单网布、不能保留未锁定走线；给了 sync 工具就要说明它不等价于 F8。
